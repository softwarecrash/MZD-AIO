AIO is fully compatible with v70 not all the tweaks are compatible but the ones that are not are skipped when running the installer.  If you did not install the autorun and recovery scripts before you updated then you have to make a [serial connection](https://mazdatweaks.com/serial/) first before you can install tweaks.
