First of all, whats you FW version?
All the autorun files are in one folder so you definitely don't need to flash your entire CMU to get rid of one folder dude.

To uninstall ie. delete that folder you just run the same script as the install script but when it prompts you for input and gives you 3 choices: "install", "uninstall", or "skip" you choose "uninstall" instead of "install"

When you select to compile the installer for the autorun scripts in AIO there are 3 additional options you can choose, one is the hotspot that would be "Automatic WiFi AP" (WiFi Access Point = hotspot) so if you don't want that then leave that option unchecked when you make the installer.
