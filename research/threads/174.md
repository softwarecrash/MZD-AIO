Did you follow theinstructions below to get the wifi configured? I have wifi configured, dont use it. I have a AAWireless transceiver plugged into the USB port of the car.

If these don't work, then I would reinstall from USB with wifi option unchecked for now and see if that fixes the blackscreen.

Install Android Auto Headunit App
AA v1.13  Wi-Fi Support  Debug Logging
(to /data/headunit.log)  Reverse Compass*
(flips the heading data 180°)  Disable Car GPS*
(only use GPS data from the phone) *If you experience reversed compass navigaion issue you can try one of these settings.Other Versions Instructions For Android Auto WiFi Support:
*(USB Support When WiFi Is Turned Off)*
0. Before you start: Activate Android Auto developer mode by going to about in the app and tapping the title bar until it says you are a developer
1. From Android Phone: Create Hotspot
2. From Vehicle: Turn on Wifi, connect to phone hotspot
3. Phone: In Android Auto app go to about screen menu and start headunit server
4. Android Auto will start automatically, if it does not or you get a black screen you can open Android Auto from the applications menu.
For more information, previous releases, or to check for new releases visit the Headunit Info Page and the Headunit Repository

Actually what it worked for me was just disabling the "media" option on the bluetooth pairing between my phone and the car. I've read something about in some mazda forums, where the Android Auto and the Car's bluetooth try to communicate at the same time with the bluetooth "media" so it is recommended to disable this in order to fully use Android auto (As AA itself comunicate completely with the phone through the android interface).

So, that basically solved my "black screen" issue.
Then i tried using it wireless following exactly those steps you wrote down, but it just didnt work. I didn't give any error, it just didn't work at all. I tried turning the hotspot on, connecting the car's wifi to the phone hotspot, then starting the headunit server, but AA didn't start. For me it just works through the USB cable.
