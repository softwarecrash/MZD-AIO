This I have a fix for in the next version but it is because you have a drive that is connected but not mounted so the drive is found and returns an object but that object is undefined because the drive isn't mounted.  This could be a drive that you left connected after ejecting or it could be a virtual drive too.  This was also a problem with Drivelist, the npm package used to find disk drives, but in the newer versions of Drivelist it has changed to a promise based system plus I still double check for the possibility of undefined drives.
