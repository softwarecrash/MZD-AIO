I just tried it on my Pixel3 on Android 10 latest March update and my CMU right now is 59.00.441A and it actually worked better than ever I was very surprised... So it must be a gStreamer issue.  I discovered an Issue with the [VideoPlayer](https://github.com/Trevelopment/Mazda-Videoplayer) app where using `mfw_v4lsink` did not work anymore around v70.  So I figured out there is another sink you can use `mfw_isink` which is just a little bit different.  Lucky for you @ksmartcar this is a very exposed piece of code located in the file [`config/castscreen-receiver/wait_adb_arm.sh`](https://github.com/JonesChi/CastScreen/blob/b989bf3f8de287ab45126bbddc6148bf84339aa4/receiver/wait_adb_arm.sh#L4) just change `./cs_receiver_arm mfw_v4lsink &` to `./cs_receiver_arm mfw_isink &` then let me know it that fixes it or even works at all.
