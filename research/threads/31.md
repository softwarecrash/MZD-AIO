### Trevelopment – 2019-07-30T23:55:45Z

[Originalkommentar](https://github.com/Trevelopment/MZD-AIO/issues/31#issuecomment-516639368) · Aktualisiert: 2019-07-30T23:56:58Z

There is a reason you have to get the upgraded USB hub to run the official AA/CP and that is because the stock hub has a shared USB port configuration while the upgraded hub changes that to an independent configuration. (actually I think stock might even split one bus between the 2 USB ports AND the SD card)
> Much like a data network, a USB port has limited bandwidth that it can share between devices. Usage varies from device to device. In an independent USB port, virtually all bandwidth – a total of 480 Mbps for 2.0 ports, and as much as 5 Gbps for 3.0 ports – is available for a single device. USB standards devote 10 percent of all data bandwidth to control, and reserve the rest for device use. In a shared environment, that bandwidth is shared between all devices. High-bandwidth peripherals, such as Web cameras or audio recorders [or a phone running Android Auto], may experience lower performance when connected to a shared USB port.

So let me ask, do you have anything using the other USB port?
