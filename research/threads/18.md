OK, that's good ,that means it is working but did you delete the `tweaks.sh` file too?  You are on a Mac? open up your flash drive after copying the files and start up a terminal in the drive  and type `chmod -R 777 .`  that will change the file permissions if that is the problem then delete all the hidden files.   The fact that you got that dialog means its working but something is wrong with your tweaks.sh file and it cant read it or run it.  You can also try reformatting the drive or try using another USB drive.  But that dialog means it will work fine when you have everything in order.
