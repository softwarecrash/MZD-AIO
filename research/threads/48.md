One thing you can do right out of the box is add shadow with the "text colors"tweak or color to the text with the  "statusbar tweaks".  if you want to make edits yourself I would suggest not editing any JavaScript files especially SpeedBarTmplt.js because a mistake in that file will brick your system.  Plus everything youre asking for can be done with CSS and you can just add it to the end of this file with the rest of the statusbar speedometer CSS [StatusBarSpeedometer.css](https://github.com/Trevelopment/MZD-AIO/blob/master/app/files/tweaks/config/speedometer/jci/gui/apps/_speedometer/css/StatusBarSpeedometer.css)
the statusbar speedometer is actually on top of everything so it is not even under #barlayout.  I dont know how much you know about DOM but the only reason you can even see it with AA running is because it is outside of the main div that holds the GUI.  Anyways that CSS file should be self explanatory if you know CSS the main div id is `#SbSpeedo` with the main value in `#SbSpeedo .SbMain` and the 2 smaller values are `#SbSpeedo .SbVal1` and `#SbSpeedo .SbVal2`
You should probably add your custom CSS to the bottom of the file but I guess if you know what you are doing you can do whatever.  Also another tip I will offer is to use outlines instead of borders.  A border will increase the width & height of the div its around and might break some formatting if you don't compensate for that while outlines wont affect the div size.
