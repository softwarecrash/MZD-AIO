I was running into this exact issue, even after trying every UN/PW combo I could find. Below is what worked for me; I take no responsibility for any damage done yadda yadda.

**tl;dr:** I had to reflash my firmware which gave me root access, bypassing the UN/PW prompt. At that point I pasted the commands from [here ](https://mazdatweaks.com/id7/)and [here](https://mazdatweaks.com/serial/#process) and rebooted. Disconnected all the wires and mods are installing just fine via USB.

**Longer:**
1. Download the [ID7 Recovery XX](https://mazdatweaks.com/id7/) file from this link instead of compiling your own.
2. Download your [firmware here](https://my.hidrive.com/share/hsodpqja.l#$/) and copy it to the USB drive.
   - Note: You don't have to upgrade necessarily. You can re-flash the same version without issue.
   - Make sure to follow the PDF instructions on that site exactly.
3. While the firmware is updating, you will need to connect via SSH and wait for the update to complete.
4. I followed the PDF instructions exactly until the progress bar reached 100%.
4. At this point the screen will ask to reboot. Don't reboot just yet!
5. You should still be connected via SSH and can now enter: `cp -r /mnt/sd*/XX/* /mnt/data_persist/dev/bin/; chmod +x /mnt/data_persist/dev/bin/autorun; /mnt/data_persist/dev/bin/autorun`
6. Finally, [finish here](https://mazdatweaks.com/serial/#process) from step 10 onwards.
7. At this point I was able to use the AIO Tweaks app, compile what I wanted and install via USB.
