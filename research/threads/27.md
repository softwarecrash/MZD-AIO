### Trevelopment – 2018-10-13T04:41:31Z

[Originalkommentar](https://github.com/Trevelopment/MZD-AIO/issues/27#issuecomment-429510674) · Aktualisiert: 2018-10-13T04:42:34Z

So you know how DOM and CSS works right?  So on boot AIO-startup.js reads the localStorage variable "aio.tweaks" and takes that variable and makes that the className of the "body" of the document.  Then attaches a CSS file that uses those classes to change the layout in some way so the star layout is something like
```
body.star1 .MainMenuCtrlAppHighlight {
    left: 120px;
    top: 40px;
}
```
and so forth then when you press reset tweaks all that does is
```
body.className = "";
```
Therefor I have to say the only conclusion I can make is that your localStorage.getItem("aio.tweaks") = "star1" so have you tried CASDK? Part of that framework is the relocation of the save location of localStorage to data_persist which is a better place for saving data.
